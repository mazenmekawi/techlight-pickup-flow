Pickup Flow — ملفات العمل المستقلة
====================================================
الإصدار: 1.1.0
معرّف التطبيق: sa.techlight.pickup.flow

مشروع شاشة استلام العملاء والتوصيل: QR الربط، استقبال الأرقام والإعدادات، العرض والأصوات.

طريقة الفتح
-----------
فك الضغط، ثم افتح المجلد TechLight-Pickup-Flow-v1.1.0 نفسه في Android Studio.
اختر المجلد الذي يحتوي settings.gradle وbuild.gradle، وليس مجلد app وحده.
هذا مشروع مستقل بوحدة واحدة :app، ولا يحتاج وجود مشروع التطبيق الآخر بجانبه أثناء البناء.
تحتاج التطبيق الآخر فقط عند تجربة الربط بين المطبخ وشاشة الاستلام.

ملفات المشروع
-------------
app/src/main/java/ : ملفات Java الأصلية اللازمة لهذا التطبيق.
app/src/main/res/ : الشعار والموارد والأصوات الأصلية المشتركة.
app/src/main/AndroidManifest.xml : تعريف التطبيق الأصلي، دون تغيير الحزمة أو الإصدار.
app/build.gradle وsettings.gradle : إعدادات البناء بعد الفصل.
tests/ وtools/test-core.sh : اختبارات المنطق المرتبطة بهذه الحزمة.
docs/ : تعليمات ووثائق مرجعية.
SOURCE-ORIGIN.json : أصل كل ملف تشغيل وبصمته.
VALIDATION.txt : نتائج فحص هذا الفصل وحدوده.

الملفات المشتركة
----------------
المصدر الأصلي كان مشروعًا موحدًا. نُسخت التبعيات اللازمة إلى كل مشروع، دون تغيير محتوى ملفات Java أو الموارد.
لا يحتوي واجهة المطبخ ولا عملاء API/تسجيل الدخول الخاص بها.
بقي الملف Session.java كما في المصدر الأصلي لأن الشاشة تستعمل دالته hash للتحقق من رمز الفصل؛ هذا ليس تسجيل دخول إلى TechPro.
تجهيز الجوال والمتوسط وقائمة الطلبات يتم في تطبيق المطبخ؛ الشاشة تستقبل لقطة العرض فقط.
حزمة Java وnamespace ما زالت sa.techlight.kitchen في المشروعين؛ هذا مقصود للحفاظ على المصدر والموارد.
applicationId مختلف لكل تطبيق كما هو موضح أعلاه. لا تغيّر package الخاصة بالكلاسات لمجرد وجود كلمة kitchen.
عند تعديل بروتوكول الربط أو التشفير لاحقًا، حافظ على التوافق بين المشروعين.

البناء
------
وفق إعدادات المصدر الأصلي: JDK 17، Android SDK 35، Gradle 8.13، وAndroid Gradle Plugin 8.9.2.
minSdk 23 وtargetSdk 32 كما في نسخة Flow الأصلية؛ ليس هذا تحديثًا لمتطلبات النشر على Google Play.
بعد تثبيت Gradle 8.13 وضبط Android SDK، من داخل مجلد المشروع:
  gradle :app:assembleDebug
  gradle :app:testDebugUnitTest
ملف البناء التجريبي المتوقع: app/build/outputs/apk/debug/app-debug.apk
اختبارات سطر الأوامر البديلة (Bash أو Git Bash):
  bash tools/test-core.sh
عند الحاجة لإضافة Gradle Wrapper محليًا:
  gradle wrapper --gradle-version 8.13 --distribution-type bin
لا توجد ملفات Gradle Wrapper في المصدر الأصلي، ولم تُضف ملفات Wrapper ثنائية إلى هذا التسليم.
قد يلزم الإنترنت أول مرة لتنزيل تبعيات البناء والاختبارات. لا توجد ملفات SDK أو مكتبات ثنائية ضمن الأرشيف.
